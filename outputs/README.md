# Generated outputs

Running `make all` creates:

- `cfa_fit_indices.csv`
- `standardized_loadings.csv`
- `reliability.csv`
- `measurement_invariance.csv`
- `sem_fit_indices.csv`
- `structural_paths.csv`
- `indirect_effects.csv`
- `r_squared.csv`
- `missingness_summary.csv`
- `residual_variances.csv`
- `modification_indices.csv`

Generated tables and fitted model objects are ignored by Git because the end-to-end workflow recreates them deterministically. The scripts are the authoritative source, and GitHub Actions validates their production.
